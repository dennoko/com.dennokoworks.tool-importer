# dennokoworks Asset Importer (BLM連携)

BOOTH Library Manager (BLM) でダウンロードした BOOTH アイテム（`.unitypackage`）を Unity エディタ内から簡単にプロジェクトへインポートするための VPM 対応パッケージです。dennokoworks 製ツールについては最新バージョンの確認もできます。

---

## 主な機能
- **BLM 連携**: BLM のデータ（`%APPDATA%\pm.booth.library-manager\data.db`）とアイテム保存先を自動検出。手動指定も可能
- **ショップ切り替え**: 既定は `dennokoworks`。BLM に登録されているショップから追加したり、サブドメインを直接入力して任意のショップを追加可能。「すべてのショップ」を選ぶと全ショップのアイテムを表示
- **インポート状態フィルター**: 「未インポート」「更新あり」「インポート済み」をワンクリックで絞り込み可能
- **軽快な無限スクロール**: 数百件を超える大量のアセットがあっても、起動やスクロールが快適なバッチ分割読み込み（無限スクロール）を採用
- **アイテム一覧**: サムネイルとツール名を表示。導入状況はボタン（インポート／再インポート／更新をインポート）で判別でき、アイテム名およびショップ名でのリアルタイム絞り込みに対応
- **ワンクリックインポート**: `.unitypackage` をインポート。複数のパッケージ（バージョン）がある場合は一覧から入れるものをチェックして選択
- **まとめてインポート**: 「複数選択モード」でチェックしたアイテムを順番にインポート（確認ダイアログの有無も切り替え可能）
- **BOOTH 商品ページ・フォルダ導線**: BLM のアイテム情報から BOOTH の商品ページや保存先フォルダを直接開く
- **最新バージョン確認**: dennokoworks 製ツールの GitHub 最新バージョン比較および Asset Importer 自体のアップデート通知に対応
- **日英バイリンガル対応**: ツールバー右上のボタンから日本語 / 英語をいつでも切り替え可能

---

## 動作環境
- Unity 2022.3 以降
- Windows 10 以降（OS 同梱の `winsqlite3.dll` を使用） / macOS（`/usr/lib/libsqlite3.dylib` を使用）
- BOOTH Library Manager

## 使い方
1. Unity メニューバーの `dennokoworks > Asset Importer` を開きます。ツールバーの「マニュアル」から使い方マニュアル（PDF）を開けます。
2. BLM が自動検出されない場合は、ツールバーの「設定」から `data.db` とアイテム保存先フォルダを指定します。
3. ツールバーのショップ名をクリックして表示するショップを切り替えます。「すべてのショップ」を選ぶとすべてのショップのアイテムを表示します。「＋」ボタンでショップを追加・管理できます。
4. 一覧から「インポート」を押すと、Unity のインポートダイアログが開きます。
   - アイテム内に複数の `.unitypackage` がある場合（ボタンに ▾ が付きます）は、パッケージ一覧が表示されるので入れるものにチェックを入れて「インポート」を押します。複数チェックした場合は古い順に 1 件ずつインポートされます。
   - 複数のツールを入れる場合は「複数選択モード」をオンにし、チェックを入れて「まとめてインポート」を押します。チェック時は最新パッケージが対象になり、複数パッケージのあるアイテムはインポートボタンの一覧から「まとめてインポート対象に設定」で対象を変更できます。1 件ずつ順番にインポートされます（「内容を確認しながら」をオンにすると 1 件ずつダイアログを表示）。
5. dennokoworks 選択時は「最新バージョン確認」で公開中の最新バージョンを確認できます。新しいバージョンがある場合は BOOTH / BLM で最新版をダウンロードし、「一覧を再読み込み」を押してください。

### 補足
- 導入状況は `.unitypackage` 内のアセット GUID がプロジェクトに存在するかで判定します。ボタンの表記（「インポート」：未導入／「再インポート」：導入済み／「更新をインポート」：BLM に新バージョンあり）で判別できます。
- バージョン情報は、更新が存在するときのみ通知メッセージが表示されます（通常時は表示を省略し、画面をシンプルに保ちます）。
- 「その他の導入済みツール」は、BLM 未登録でもプロジェクト内に `version.json` を持つ dennokoworks 製ツールが表示されます。
- 解析結果は `Library/DennokoworksToolImporter/` にキャッシュされます。
- ショップ一覧と BLM パスの手動指定、言語設定は `EditorPrefs` に保存され、全プロジェクトで共通です。
- BOOTH の商品名に含まれる一部の絵文字や特殊装飾記号は、Unity UI Toolkit のフォント描画（TextCore SDF）の制限により「□」と表示される場合がありますが、インポート等の動作には影響ありません。
