# dennokoworks Tool Importer (BLM連携) ユーザーマニュアル

**dennokoworks Tool Importer** は、**BOOTH Library Manager (BLM)** と連携し、ダウンロード済みの Unity パッケージ（`.unitypackage`）を Unity エディタ内から簡単に検索・インポートできる Unity エディタ拡張ツールです。

## 1. 概要・主な機能

- **BLMライブラリからの直接インポート**: BOOTH Library Manager でダウンロードされたアセットを自動検出し、Unity から直接プロジェクトへインポートできます。
- **シンプルなステータス判定**: ボタンの表記（`インポート` / `再インポート` / `更新をインポート`）だけで、プロジェクトへの導入状況が直感的に分かります。
- **インポート状態フィルター**: 「未インポート」「更新あり」「インポート済み」をワンクリックで絞り込み可能です。
- **柔軟なショップ絞り込み**: デフォルトの全ショップ表示（すべてのショップ）のほか、`dennokoworks` や任意の BOOTH ショップ単位でアイテムを絞り込めます。
- **まとめてインポート**: 「複数選択モード」でチェックした複数のアセットをワンクリックで順次インポートできます。
- **軽快な無限スクロール**: 数百件を超える大量のアセットがあっても、起動やスクロールが快適に行えるバッチ分割読み込み（無限スクロール）を採用しています。
- **アップデート確認**: dennokoworks 製ツールの場合、最新バージョンが公開されているかを自動チェックし、更新案内を表示します。Tool Importer 自体の更新もヘッダーから確認できます。
- **日英バイリンガル対応**: ワンクリックで日本語 / 英語表示を切り替えられます。

## 2. 動作環境

| 項目 | 要件 |
| :--- | :--- |
| **Unity バージョン** | Unity 2022.3 以降 |
| **対応OS** | Windows 10 / 11, macOS |
| **必須ソフトウェア** | [BOOTH Library Manager (BLM)](https://booth.pm) がインストールされ、アイテムがダウンロードされていること |

> [!NOTE]
> 本ツールは BLM が管理するローカルデータベースファイル（`data.db`）を参照して動作します。BLM でアイテムのダウンロードが行われている必要があります。

## 3. 導入方法（インストール）

### VCC (VRChat Creator Companion) 経由で導入する場合

1. 配布されている VPM リポジトリ追加リンクをクリックし、VCC にリポジトリを登録します。
2. 対象プロジェクトの「Manage Project」を開きます。
3. パッケージ一覧から **dennokoworks Tool Importer** を探し、`+` ボタンを押してプロジェクトに追加します。

---

## 4. ツールの起動

Unity エディタの上部メニューバーから以下を選択します。

```text
dennokoworks > Tool Importer
```

※ `Tools > dennokoworks > Tool Importer` からも開けます。

## 6. 初期設定（BLM連携）

ツール起動時、BLM のデータベースファイル（`data.db`）およびアイテム保存先が自動的に検索されます。

- **自動検出された場合**: 設定不要で即座にアイテム一覧が表示されます。
- **検出されなかった場合**: 「設定」パネルが自動展開され、パスの指定を促す案内が表示されます。「参照...」ボタンからお使いの環境の `data.db` または保存先フォルダを指定してください。「自動」ボタンを押すといつでも自動検出に戻せます。
- **キャッシュ削除**: パッケージ解析情報に不整合がある場合は、設定パネル内の「パッケージ解析キャッシュを削除」をクリックしてください。

> [!TIP]
> **一般的な `data.db` の配置場所**
> - **Windows**: `%APPDATA%\pm.booth.library-manager\data.db`  
>   （例: `C:\Users\<ユーザー名>\AppData\Roaming\pm.booth.library-manager\data.db`）
> - **macOS**: `~/Library/Application Support/pm.booth.library-manager/data.db`

## 7. ショップの選択と管理

### ショップの切り替え
ナビゲーションバーの「ショップ: [ 選択中のショップ名 ▾ ]」をクリックすると、ドロップダウンメニューが表示されます。

- **すべてのショップ**: ショップによる絞り込みを行わず、BLM にある対象アイテムをすべて表示します。
- **dennokoworks**: dennokoworks 製のツール・アセットのみに絞り込みます（バージョン自動確認機能が有効になります）。
- **その他の登録ショップ**: ご自身で登録したショップ名でアイテムを絞り込めます。

### ショップ管理画面の操作
ドロップダウンメニューの「ショップを追加・管理...」またはナビゲーションバーの「**＋**」ボタンを押すと、ショップ管理画面が開きます。

1. **BLM からショップを追加**: BLM 内に購入履歴があるショップの一覧から選択して追加できます。
2. **サブドメイン直接入力で追加**: BOOTH のサブドメイン（`https://[subdomain].booth.pm` の `[subdomain]` 部分）を入力して追加できます。
3. **ショップの削除**: 一覧の各ショップ右横にある「削除」ボタンをクリックします（※ `dennokoworks` は初期登録ショップのため削除できません）。

### デフォルトショップの設定
ショップ管理画面の上部にある「**起動時のデフォルトショップ**」設定から、次回起動時に最初に選択されるショップを指定できます。

## 8. アイテム一覧の見方と操作

### アイテムの検索・ステータス絞り込み
- **キーワード検索**: 検索フィールドに文字を入力すると、アイテム名およびショップ名でリアルタイムに絞り込みが行われます。
- **ステータスフィルター**: 検索バー横の「▼ 全て」ボタンから、以下の条件で一覧をフィルタリングできます：
  - **全て**: すべてのアイテムを表示
  - **未インポート**: プロジェクトにまだインポートされていないアイテムのみ表示
  - **更新あり**: BLM 内に新しいバージョンが存在するアイテムのみ表示
  - **インポート済み**: プロジェクトに導入済みのアイテムのみ表示

### 無限スクロール表示
アイテム一覧はパフォーマンス向上のため、初期状態で 30 件が表示され、スクロールバーを下端に近づけると次の 30 件が自動的に読み込まれます。未読み込みのアイテムがある場合はリスト末尾の「さらに読み込む (残り N 件)」ボタンをクリックしても追加できます。

### ボタン表示と導入状態の見分け方
各アイテムカードの右下に表示されるボタンの種類と色で、プロジェクトへの導入状態が分かります。

| ボタン表記 | 色 | 状態 | 説明 |
| :--- | :--- | :--- | :--- |
| **インポート** | 青色 | 未導入 | 現在開いている Unity プロジェクトにまだインポートされていません。 |
| **再インポート** | グレー | 導入済み | すでにプロジェクトにインポート済みです。上書きインポートしたい場合に使用します。 |
| **更新をインポート** | オレンジ色 | アップデートあり | プロジェクトに導入されているものより、BLM 内に新しいパッケージが存在します。 |
| **パッケージなし** | 無効 | パッケージなし | `.unitypackage` が見つからないためインポートできません。 |

※ アイテム内に複数の `.unitypackage` が含まれる場合、ボタン右側に「▾」マークが表示されます。

### 警告アイコン（非表示・未展開アイテムの確認）
アイテム件数表示の横に黄色い注意アイコン（⚠️）が表示されている場合があります。
マウスカーソルを合わせると、ツールチップで以下の詳細が表示されます：
- **`.unitypackage` が見つからないアイテム数**: 3Dモデルデータのみのアイテムやアセット類
- **zip が未展開の可能性があるアイテム数**: BLM 上で zip 解凍を行ってから「一覧を再読み込み」を押してください。

## 9. インポート手順

### 単体インポート
1. インポートしたいアイテムの右側にある「**インポート**」ボタンをクリックします。
2. Unity 標準のパッケージインポート確認ダイアログが表示されたら、内容を確認して「Import」を実行します。

### 複数パッケージが含まれる場合の選択ポップアップ
1つのアイテム内にバージョン違いやバリエーションなど複数の `.unitypackage` が含まれている場合、インポートボタンを押すとパッケージ選択ポップアップが表示されます。
一覧からインポートしたいファイルを選択して「インポート」をクリックしてください。

### まとめてインポート（一括導入）
1. 操作バーの「**複数選択モード**」にチェックを入れます。各アイテムカードにチェックボックスが表示されます。
2. インポートしたいアイテムにチェックを入れます。
   - 「すべて選択」: 一覧の対象アイテムをすべて選択
   - 「更新ありを選択」: 更新が存在するアイテムのみを選択
   - 「選択解除」: 選択を全解除
3. **内容を確認しながら**: チェックをオンにすると、1 件ごとに Unity のインポート確認ダイアログが表示されます。オフにすると確認なしで連続インポートが行われます。
4. 「**まとめてインポート (N 件)**」ボタンをクリックすると順次インポートが実行されます。
5. インポート中は進捗バーが表示され、「現在の項目をスキップ」や「残りを中止」が可能です。

## 10. その他の導入済みツール（プロジェクト内ツール管理）

プロジェクト内の `Assets/dennokoworks/` フォルダ配下に導入されている dennokoworks 製ツールのうち、BLM の管理外（手動配置や別経路で導入されたもの）が存在する場合、アイテム一覧の下部に「**その他の導入済みツール**」として表示されます。

- **バージョンチェック**: 各ツールの GitHub Releases と通信し、新しいバージョンが存在するか自動判定します。
- **選択**: クリックすると Project ウィンドウ内で該当ツールの `version.json` をハイライト（Ping）します。
- **BOOTH**: 配布元の BOOTH ショップページを開きます。

## 11. 言語の切り替え（日本語 / 英語）

ウィンドウ右上の「**EN / JA**」ボタンをクリックすることで、UI の表示言語を即座に切り替えることができます。
設定は保存され、次回起動時も保持されます。

> [!NOTE]
> UI を英語に切り替えている場合、ナビゲーションバーの「Manual」ボタンを押すと英語版マニュアル（`Docs/user_manual_en.pdf`）が開きます（※ 英語版 PDF が存在しない場合は自動的に日本語版 PDF が開きます）。

## 12. よくある質問・トラブルシューティング

### Q. 商品名の一部が「□」（四角・トーフ）と表示されます
**A.** BOOTH の商品名に含まれる一部の絵文字（🐾、🎀、👗 等）や特殊な装飾記号は、Unity UI Toolkit のフォント描画（TextCore SDF）においてフォント（メイリオ等）にグリフが含まれていない場合に「□」として描画されます。  
これは表示上のフォント制限によるものであり、パッケージの検索、インポート処理、およびツールの正常な動作には一切影響ありません。

### Q. BLM でダウンロードしたはずのアイテムが一覧に表示されません
**A.** 以下の点をご確認ください：
1. **zip ファイルが展開されているか**: BLM の設定でダウンロード後に自動展開する設定になっているか確認してください。zip のまま保存されている場合、パッケージを検出できません。
2. **`.unitypackage` が含まれているか**: アイテム内に `.unitypackage` 形式のファイルが存在しないアイテム（FBX やテクスチャ画像のみなど）は自動的に除外されます。除外件数はアイテム件数横の警告アイコンから確認できます。
3. **ショップフィルタ・ステータスフィルタの設定**: 目的のアイテムが現在選択しているショップおよびステータスフィルター（「未インポート」等）と一致しているか確認してください。ショップを「すべてのショップ」、フィルターを「▼ 全て」に切り替えて検索をお試しください。

### Q. インポートが途中で止まってしまった・進まない
**A.** キュー表示カードの「現在の項目をスキップ」を押して次のアイテムに進むか、「残りを中止」を押して一括処理を中断してください。

### Q. アイテム一覧の更新が反映されません
**A.** BLM 側で新しくアイテムをダウンロードしたり削除したりした場合は、操作バーの「**一覧を再読み込み**」ボタンを押してキャッシュとライブラリ情報をリフレッシュしてください。
