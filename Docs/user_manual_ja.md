# dennokoworks Tool Importer (BLM連携) ユーザーマニュアル

**dennokoworks Tool Importer** は、**BOOTH Library Manager (BLM)** と連携し、ダウンロード済みの Unity パッケージ（`.unitypackage`）を Unity エディタ内から簡単に検索・インポートできる Unity エディタ拡張ツールです。

## 1. 概要・主な機能

- **BLMライブラリからの直接インポート**: BOOTH Library Manager でダウンロードされたアセットを自動検出し、Unity から直接プロジェクトへインポートできます。
- **シンプルなステータス判定**: ボタンの表記（`インポート` / `再インポート` / `更新をインポート`）だけで、プロジェクトへの導入状況が直感的に分かります。
- **柔軟なショップ絞り込み**: デフォルトの全アイテム表示（None）のほか、`dennokoworks` や任意の BOOTH ショップ単位でアイテムを絞り込めます。
- **まとめてインポート**: 複数のアセットにチェックを入れて、ワンクリックで順次インポートできます。
- **アップデート確認（dennokoworks限定）**: dennokoworks 製ツールの場合、最新バージョンが公開されているかを自動チェックし、更新案内を表示します。

## 2. 動作環境

| 項目 | 要件 |
| :--- | :--- |
| **Unity バージョン** | Unity 2022.3 以降 |
| **対応OS** | Windows 10 / 11, macOS |
| **必須ソフトウェア** | [BOOTH Library Manager (BLM)](https://booth.pm) がインストールされ、アイテムがダウンロードされていること |

> [!NOTE]
> 本ツールは BLM が管理するローカルデータベースファイル（`data.db`）を参照して動作します。BLM でアイテムのダウンロードが行われている必要があります。

## 3. 導入方法（インストール）

### VCC (VRChat Creator Companion) 経由で導入する場合

1. 配布されている VPM リポジトリ追加リンクをクリックし、VCC にリポジトリを登録します。
2. 対象プロジェクトの「Manage Project」を開きます。
3. パッケージ一覧から **dennokoworks Tool Importer** を探し、`+` ボタンを押してプロジェクトに追加します。

---

## 4. ツールの起動

Unity エディタの上部メニューバーから以下を選択します。

```text
Tools > dennokoworks > Tool Importer
```

ウィンドウが表示され、BLM ライブラリの読み込みが開始されます。

---

## 5. 初期設定（BLM連携）

ツール起動時、BLM のデータベースファイル（`data.db`）が自動的に検索されます。

- **自動検出された場合**: 設定不要ですぐにアイテム一覧が表示されます。
- **検出されなかった場合**: ウィンドウ上部に「BLM のデータベースファイルが見つかりません」という案内が表示されます。右側の「設定」または「参照...」ボタンから、お使いの環境の `data.db` を指定してください。

> [!TIP]
> **一般的な `data.db` の配置場所**
> - **Windows**: `%APPDATA%\pm.booth.library-manager\data.db`  
>   （例: `C:\Users\<ユーザー名>\AppData\Roaming\pm.booth.library-manager\data.db`）
> - **macOS**: `~/Library/Application Support/pm.booth.library-manager/data.db`

## 6. ショップの選択と管理

### ショップの切り替え
ウィンドウ上部の「ショップ: [ 選択中のショップ名 ▼ ]」をクリックすると、ドロップダウンメニューが表示されます。

- **None（デフォルト）**: ショップによる絞り込みを行わず、BLM にある対象アイテムをすべて表示します。
- **dennokoworks**: dennokoworks 製のツール・アセットのみに絞り込みます（バージョン確認機能が有効になります）。
- **その他の追加ショップ**: ご自身で登録したショップ名でアイテムを絞り込みます。

### ショップ管理画面の操作
ドロップダウンメニュー一番下の「**ショップの管理...**」を選択すると、ショップ管理ウィンドウが開きます。

1. **ショップの新規追加**:
   - 下部の入力欄に BOOTH のショップ名（またはサブドメイン名）を入力し、「追加」ボタンをクリックします。
2. **ショップの削除**:
   - 一覧の各ショップ右横にある「削除」ボタンをクリックします。
   - ※ `dennokoworks` は初期登録ショップのため削除できません。
3. **登録名の編集**:
   - ショップ名を直接編集できます。

### デフォルトショップの設定
ショップ管理ウィンドウの上部にある「**起動時のデフォルトショップ**」設定から、次回 Unity 起動時やウィンドウを開いた際に最初に選択されるショップを指定できます。

- デフォルト設定: **None**
- 必要に応じて `dennokoworks` やよく使うショップに変更可能です。

## 7. アイテム一覧の見方と操作

### アイテムの検索・フィルタリング
上部の検索バーにキーワードを入力すると、アイテム名でリアルタイムに絞り込みができます。

### ボタン表示と導入状態の見分け方
各アイテムの右側に表示されるボタンの種類と色で、プロジェクトへの導入状態が分かります。

| ボタン表記 | 状態 | 説明 |
| :--- | :--- | :--- |
| **インポート**（青色） | 未導入 | 現在開いている Unity プロジェクトにまだインポートされていません。 |
| **再インポート**（白色） | 導入済み | すでにプロジェクトにインポート済みです。上書きインポートしたい場合に使用します。 |
| **更新をインポート**（オレンジ色） | アップデートあり | プロジェクトに導入されているものより、BLM 内に新しいパッケージが存在します。 |

### 警告アイコン（非表示・未展開アイテムの確認）
アイテム件数表示の横に黄色い注意アイコン（⚠️）が表示されている場合があります。

- アイコンにマウスカーソルを合わせる（マウスオーバーする）と、以下の詳細がツールチップで表示されます：
  - **`.unitypackage` が見つからなかったアイテム数**（3Dモデルデータのみのアイテムやアセット類）
  - **zip ファイルが未展開のアイテム数**
- ※画面をすっきり保つため、常時テキストではなくツールチップ形式で必要な時のみ確認できるようになっています。

## 8. インポート手順

### 単体インポート
1. インポートしたいアイテムの右側にある「**インポート**」ボタンをクリックします。
2. Unity 標準のパッケージインポート確認ダイアログが表示されたら、内容を確認して「Import」を実行します。

### 複数パッケージが含まれる場合の選択ポップアップ
1つのアイテム内にバージョン違いやバリエーションなど複数の `.unitypackage` が含まれている場合、インポートボタンを押すとパッケージ選択ポップアップが表示されます。
一覧からインポートしたいファイルを選択してインポートしてください。

### まとめてインポート（一括導入）
1. 各アイテムの左側にあるチェックボックスにチェックを入れます。
2. 最上部の「全選択」にチェックを入れると、一覧に表示されている全アイテムを一括選択できます。
3. 上部の「**選択したアイテムをインポート (N件)**」ボタンをクリックします。
4. インポート処理が順番に実行されます。進行状況はプログレスバーに表示されます。

## 9. バージョン確認機能（dennokoworks限定）

ショップで **dennokoworks** を選択している場合のみ、各ツールの最新バージョン情報が自動的に確認されます。

- **最新版を使用している場合**: 特別なメッセージは表示されず、画面をシンプルに保ちます。
- **新しいバージョンがリリースされている場合**: アイテム行内にアップデート通知が表示されます。
  - BOOTH Library Manager（BLM）を起動して最新版のダウンロードを行ってください。
  - ダウンロード完了後、本ツールの「再読み込み」ボタンを押すと「更新をインポート」ボタンに切り替わります。

## 10. よくある質問・トラブルシューティング

### Q. BLM でダウンロードしたはずのアイテムが一覧に表示されません
**A.** 以下の点をご確認ください：
1. **zip ファイルが展開されているか**: BLM の設定でダウンロード後に自動展開する設定になっているか確認してください。zip のまま保存されている場合、パッケージを検出できません。
2. **`.unitypackage` が含まれているか**: アイテム内に `.unitypackage` 形式のファイルが存在しないアイテム（FBX やテクスチャ画像のみなど）は自動的に除外されます。除外件数はアイテム件数横の警告アイコンから確認できます。
3. **ショップフィルタの設定**: 目的のアイテムが現在選択しているショップと一致しているか確認してください。見当たらない場合はショップを「None」に切り替えて全体を検索してください。

### Q. インポートのプログレスバー（進行ゲージ）が完了しても消えません
**A.** Unity のコンパイルやドメインリロードのタイミングによってゲージの更新が遅れる場合があります。通常は処理完了または数秒のタイムアウトで自動的に非表示になりますが、消えない場合はウィンドウ上部の「再読み込み」ボタンを押すか、ウィンドウを一度閉じて再度開いてください。

### Q. アイテム一覧の更新が反映されません
**A.** BLM 側で新しくアイテムをダウンロードしたり削除したりした場合は、ウィンドウ上部の「**再読み込み**」ボタンを押してキャッシュとライブラリ情報をリフレッシュしてください。
